## Project Description

Whimsy is a modern-day social media application that helps people share their feelings in a short and crisp way. It uses Firebase for authentication and data storage and offers features like: following, profile editing, and search functionality. *The app is currently in it development stage and we are working on some exciting features that make it different from all other social media apps.
## Key Features

- [Follow and Following]: Users can follow other users. and see what others posting.
- [Sign-in & Sign-up]: Users can logout from the app to keep their account secure.
- [Tag your Friends]: Users can tag other users who use Whimsy, to their moods.
-  Suggested Users
We have implemented a Suggested Users feature that recommends users to follow based on the people you follow. When you follow a user, the system suggests other users who are also followed by people you follow, making it easier to discover new accounts that align with your interests.
- Mood-Based Image Generation
Another feature we added is the Mood-Based Image Generation. When writing a mood, if you include the hashtag #generate-image after your input, an image will be generated based on the mood or description provided. This allows users to visually express their emotions or thoughts through AI-generated artwork.
- Mood's Reason Generation
In addition to the image generation, we also implemented a feature where, by using the hashtag #generate-response, the system generates a response explaining the reason behind the mood. This response provides insight into why the mood was chosen and adds context to the user’s emotional state.

These features were implemented using DALL·E for image generation and response generation based on user input.
